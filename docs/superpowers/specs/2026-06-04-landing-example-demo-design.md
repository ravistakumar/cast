# cast — Landing Example + Demo GIF: Design

**Status:** Approved design (pre-implementation)
**Date:** 2026-06-04
**Author:** Ravi S

## Summary

Add a real, bundled example skill that `cast` compiles, plus a README demo GIF
matching the `prr`/`fan` family look. No new Go code or tests — this is example
content and documentation.

## Components

### 1. Example skill — `examples/changelog/`

```
examples/changelog/
  SKILL.md             # name: changelog, description, body
  scripts/
    collect-commits.sh # collect commits since the last git tag
```

- `SKILL.md` frontmatter: `name: changelog`, a one-line `description`.
- The body describes generating release notes from git history and references
  the **`Grep`** tool to scan commit messages. This is a deliberate, realistic
  choice: `Grep` has **no Codex equivalent** (so `cast build --target codex`
  emits a `tool-no-equivalent` warning) but **maps to `grep` for Cursor** (clean).
  A single `cast build` therefore demonstrates per-harness divergence with a
  genuine warning.
- `scripts/collect-commits.sh` is a small, correct POSIX shell helper
  (`git log <last-tag>..HEAD --pretty=...`). It is illustrative content copied
  verbatim by `cast`; it is not executed by `cast`.

### 2. Demo — `docs/demo.tape`, `docs/demo/render.sh`, `docs/demo.gif`

- `docs/demo.tape`: a [VHS](https://github.com/charmbracelet/vhs) tape using the
  family style (`Set Shell "bash"`, `FontSize 20`, `Width 1200`, `Height 760`,
  `Padding 24`, `Theme "Catppuccin Mocha"`). It runs:
  - `cast targets`
  - `cast build examples/changelog --target codex,cursor`
  - a `find dist -type f` (or `ls -R dist`) to show both harness-native trees and
    the Codex `Grep` warning on stderr.
  - `Output docs/demo.gif`.
- `docs/demo/render.sh`: builds the binary, puts it first on `PATH`, and runs
  `vhs docs/demo.tape`. Because `cast build` is deterministic and agent-free, the
  demo needs **no fake agent** (simpler than `prr`'s tape).
- `docs/demo.gif`: generated by rendering the tape. If headless VHS cannot run in
  the current environment, the tape + `render.sh` are committed (fully
  reproducible) and the GIF is produced with `sh docs/demo/render.sh`.

### 3. README changes

- Add `![cast demo](docs/demo.gif)` to the centered header block (matching
  `prr`/`fan`).
- Add a short **Example** section that points at `examples/changelog/`, shows the
  `cast build examples/changelog` command, and the resulting `dist/` tree.

## Verification

- `cast check examples/changelog` succeeds (valid canonical input).
- `cast build examples/changelog --target codex,cursor` produces:
  - `dist/codex/skills/changelog/SKILL.md` + `agents/openai.yaml` + `scripts/collect-commits.sh`
  - `dist/cursor/skills/changelog/SKILL.md` + `scripts/collect-commits.sh`
  - a `tool-no-equivalent` warning for `Grep` under `codex` and **not** under `cursor`.
- The existing Go test suite remains green (unchanged).

## Scope

**In:** the `examples/changelog/` skill, the VHS tape + render script, the
generated `docs/demo.gif` (or the reproducible tape if it can't be rendered here),
and the two README additions.

**Out:** new Go code, new commands, additional example skills, a social-preview
image (`prr` has one; deferred), CI rendering of the GIF.
